# 即時聊天與社群平台（Realtime Chat & Community Platform）

## 一、專案介紹

本專案為「現代軟體工程」課程實作，目標是開發一個具有 Discord 風格的聊天與社群平台。

使用 HTML、CSS、JavaScript 建立網頁介面，並透過瀏覽器的 localStorage 與 sessionStorage 模擬會員登入、訊息儲存、好友管理、群組聊天及通知系統。

目前版本為前端展示系統，可在同一瀏覽器中切換不同測試帳號，模擬使用者之間的互動。

## 二、專案目標

1. 建立具有完整操作介面的聊天平台。
2. 實作會員註冊、登入與登出。
3. 提供文字頻道與私人聊天功能。
4. 建立好友邀請及好友管理系統。
5. 支援多人群組聊天與群組管理。
6. 加入訊息已讀狀態與通知中心。
7. 透過功能測試確認各項操作正常。

## 三、主要功能

### 1. 會員系統
- 註冊新帳號
- 會員登入與登出
- 使用 sessionStorage 保存登入狀態

### 2. 文字頻道
- 一般聊天
- 程式討論
- 遊戲交流
- 切換不同聊天頻道
- 保存頻道訊息

### 3. 好友系統
- 搜尋會員
- 發送好友邀請
- 接受或拒絕邀請
- 顯示好友列表
- 刪除好友

### 4. 私人聊天
- 與好友進行一對一聊天
- 保存私人訊息紀錄
- 顯示已讀與未讀狀態

### 5. 群組聊天
- 建立聊天群組
- 邀請好友加入群組
- 傳送及查看群組訊息
- 顯示群組成員
- 成員離開群組
- 建立者解散群組

### 6. 通知中心
- 好友邀請通知
- 私人訊息通知
- 群組邀請通知
- 顯示未讀通知數量
- 單筆通知標記已讀
- 全部標記已讀
- 清空通知

## 四、使用技術

| 技術 | 用途 |
|---|---|
| HTML5 | 建立網頁結構 |
| CSS3 | 設計 Discord 風格深色介面 |
| JavaScript | 處理聊天與社群功能 |
| localStorage | 儲存會員、訊息、好友、群組與通知 |
| sessionStorage | 保存目前瀏覽器分頁的登入狀態 |
| Visual Studio Code | 程式開發與編輯 |

- `friends.js`：好友與好友邀請功能
- `private-chat.js`：私人聊天訊息管理

- `notifications.js`：通知資料管理
- `README.md`：專案說明文件

## 六、執行方式

本專案為純前端網頁，不需要額外安裝 Node.js、Docker 或資料庫。

1. 下載或複製專案資料夾。
2. 使用 Chrome 等瀏覽器開啟 `auth.html`。
3. 註冊測試帳號並登入。
4. 進入 `index.html` 操作聊天平台。
5. 可使用不同測試帳號模擬好友、私人聊天與群組功能。

## 八、目前限制

本專案為課程展示版本，並非正式上線的即時通訊服務。

- 資料儲存在本機瀏覽器中，不同裝置之間無法直接共享。
- 不具備真正的後端伺服器及 WebSocket 即時通訊。
- 使用者登入與密碼儲存僅供功能展示，不適合儲存真實帳號密碼。
- 通知與已讀功能以瀏覽器本機資料模擬。
- 清除瀏覽器網站資料後，部分測試資料可能遺失。

## 九、未來改進方向

4. 支援不同裝置之間的資料同步。
5. 加入圖片傳送、檔案上傳與更多聊天功能。
6. 建立自動化單元測試、API 測試與端對端測試。

## 十、專案心得

本次專案從基本聊天介面開始，逐步加入會員登入、好友管理、私人聊天、群組管理、訊息已讀及通知系統。

開發過程中，我學習到如何將不同功能拆分為獨立的 JavaScript 檔案，並利用 localStorage 保存資料，使網頁重新整理後仍能保留聊天紀錄。

在整合多個功能時，也需要注意資料格式、函式呼叫順序及不同功能之間的關聯。透過逐步開發、手動測試及修正介面問題，讓整個專案從簡單的聊天頁面擴充成具有多種社群功能的展示平台。

這次實作讓我更了解軟體工程中功能規劃、模組化設計、系統整合及測試的重要性。
