
# 即時聊天與社群平台（Realtime Chat & Community Platform）

## 一、專案介紹

本專案為《現代軟體工程》課程實作作品，目標是建立一個具有會員管理、公共聊天、好友互動及群組管理功能的網頁聊天平台。

使用 HTML、CSS 與 JavaScript 開發，並透過瀏覽器的 LocalStorage 與 SessionStorage 保存資料及登入狀態。

本專案從基本聊天介面開始，逐步加入會員系統、私人聊天、群組功能及公共聊天頻道，並透過不同帳號進行功能測試。

## 二、使用技術

| 技術 | 用途 |
|---|---|
| HTML5 | 網頁結構 |
| CSS3 | 網頁介面與排版 |
| JavaScript | 聊天功能與事件處理 |
| LocalStorage | 儲存會員及聊天資料 |
| SessionStorage | 保存登入狀態 |
| Git / GitHub | 程式碼版本管理 |
| Cloudflare Pages | 網站部署 |
| Playwright | E2E 自動化測試（規劃中） |

## 三、主要功能

### 1. 會員系統

- 會員註冊
- 會員登入
- 登出功能
- 登入狀態管理
- 帳號資料驗證

### 2. 公共聊天頻道

平台提供三個公共聊天頻道：

- 💬 一般聊天
- 💻 程式討論
- 🎮 遊戲交流

功能說明：

- 不同會員可以在相同頻道傳送訊息。
- 各頻道具有獨立聊天紀錄。
- 可以自由切換聊天頻道。
- 同一瀏覽器環境下，不同分頁可同步公共聊天訊息。

### 3. 好友系統

- 搜尋會員
- 發送好友邀請
- 接受好友邀請
- 好友列表管理
- 防止使用者加入自己
- 找不到會員時顯示提示

### 4. 私人聊天

- 好友之間傳送私人訊息
- 顯示聊天紀錄
- 訊息時間顯示
- Enter 鍵傳送訊息
- 訊息已讀與未讀狀態

### 5. 群組聊天

- 建立群組
- 邀請好友加入群組
- 群組成員共同聊天
- 顯示群組聊天紀錄
- 成員離開群組
- 群組建立者解散群組

### 6. 社群快捷功能

左側提供四個快捷圖示：

| 圖示 | 功能 |
|---|---|
| 💬 | 切換一般聊天 |
| 💻 | 切換程式討論 |
| 🎮 | 切換遊戲交流 |
| ➕ | 前往建立群組輸入區域 |

- `script.js`：聊天主程式及公共頻道
- `auth.js`：會員驗證與登入管理
- `friends.js`：好友管理
- `private-chat.js`：私人聊天
- `groups.js`：群組管理
- `read-status.js`：訊息已讀狀態
- `notifications.js`：通知功能
- `README.md`：專案說明文件

## 五、使用方式

1. 開啟網站。
2. 註冊新帳號或登入既有帳號。
3. 進入聊天主頁。
4. 選擇一般聊天、程式討論或遊戲交流。
5. 輸入訊息並送出。
6. 可以使用好友功能建立私人聊天。
7. 也可以建立群組並邀請好友加入。

### 公共聊天測試說明

使用 student01 與 student02 兩個測試帳號，在同一瀏覽器環境的不同分頁進行測試。

測試內容：

1. student01 登入聊天平台。
2. student02 在另一個分頁登入。
3. student01 進入公共聊天頻道並傳送訊息。
4. student02 進入相同頻道。
5. 確認 student02 能看到 student01 的訊息。
6. 分別測試一般聊天、程式討論與遊戲交流。

測試結果：三個公共頻道均成功顯示共享訊息。

## 八、目前系統限制

本專案目前以瀏覽器本機儲存為主。

- 聊天紀錄儲存在 LocalStorage。
- 不同瀏覽器或不同裝置無法直接共享聊天資料。
- 公共聊天同步目前僅適用於同一瀏覽器環境。
- 尚未建立雲端資料庫及正式後端伺服器。
- 會員資料與密碼管理為課程展示用途，不適合直接用於正式服務。

未來可透過 Firebase 或其他後端服務改善跨裝置同步、資料儲存與帳號安全性。
